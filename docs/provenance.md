# 公开版的提炼依据与边界

整理日期：2026-10-13。公开版从 TBD 本地制作规范 v0.3、早期试播迭代、后续多机位长访谈的制作记录，以及字幕／包装／音轨验证经验中重新编写。旧工程仍是私有制作材料，本仓库提供可独立理解和使用的方法。

本次查阅了规范、脚本、依赖声明和检查记录；没有重新观看全部节目、重新推理所有模型或重新渲染历史单集。公开版不是原项目原样镜像，也不能靠本库复现未公开的实际节目。

| 提炼出的经验 | 在公开版中的表达 | 不应推导出的结论 |
|---|---|---|
| 相机分段、重启和长录制漂移 | 每段独立同步，检查首中尾与接头，记录可用覆盖 | 文件相邻就连续；一次相关峰适用整期 |
| 用户指定处理后素材 | 明确替代范围，锁定当前源身份并重建映射 | 为追求画质可以私自混回旧源 |
| 精确 seek 与源时钟不一致 | 在共享取帧层检查 PTS，必要时预读后按源时钟裁切 | 给所有节目叠加历史偏移就能同步 |
| 短应答被合入他人的字幕 | 回合优先，未知归属独立，SRT 与画面同源 | ASR 分段或声纹分数就是人物事实 |
| 局部声音处理 | 记录区间、复听前后，并检验未修改范围 | 全局去点击一定无损；平均响度代表逐句平衡 |
| 封装后音轨尾部缺包 | 检查最终输出的包时间戳、完整尾部和总时长 | 中段相关性通过就证明整条声音完整 |
| 横版与包装分阶段审片 | 分别记录技术检查、实际听看、确认和发布 | 粗剪风格认可等于最终内容已批准 |

配色和布局被保留为可调整起点；具体人物、原话、敏感叙述、私有素材文件名、本机绝对路径和原节目媒体没有纳入公开版。示例文字及 JSON 是新写的虚构内容，不来自真实访谈。

六个 skills 是对这些方法的原创整理。依赖文档链接上游安装与许可证入口，不打包其他作者的技能、模型或程序。原项目中有大量绑定单集路径、素材身份和人工决定的脚本，未将它们伪装成通用渲染器；本库的小工具专门演示可共享的记录契约。

今后规范变化应附新证据与适用范围；已有单集的参数、检查数量或模型版本不是永久要求。社区端到端制作经验可通过贡献补充，但应明确哪些环节实际运行、哪些仍未人工审核。
