# 质量检查单

复制到单集记录时，为每项填 `通过 / 失败 / 未检查 / 不适用`，同时记录对应版本、文件身份、方法、实际范围与证据。空白不能解释为通过。使用[审片报告模板](../templates/review-report.md)汇总。

本页列的是检查责任，不能因为运行一次脚本就全部勾选。规则依据见[制作规范](production-standard.md)，阶段顺序见[制作流程](workflow.md)。

## 1. 当前制作依据

- [ ] 当前使用的源、角色、机位、音轨和替代关系有明确清单及哈希；未混入旧源。
- [ ] 原片只读保留，代理与最终制作源区分清楚；缺录与原片位置有记录。
- [ ] 所有相邻分段、重启文件已核查，首次使用完整解码；未假定文件自然连续。
- [ ] 包装所依据的正文确认或本轮继续制作授权可以定位到具体版本和范围。
- [ ] 正文审片、字幕听审、技术验证与发布状态分别记录，没有补写未发生的确认。

## 2. 内容、镜头与真实反应

- [ ] 问答、否定、数字和限定完整；删段没有改变因果或人物意思。
- [ ] 删除停顿的候选已回听原音；没有按 ASR 空白、固定秒数或删除比例自动清理。
- [ ] 笑点的建立与反应顺序成立；没有异时反应、补写对白或假笑轨。
- [ ] 稳定发言、短问答、画外插话和缺录段各有合适机位；未机械轮换。
- [ ] 每个剪口的词头、尾音、呼吸、动作和底噪已检查，未用淡变掩盖语音缺失。
- [ ] 严肃段落的花字与音效符合实际情绪，编辑小字与人物原话可区分。
- [ ] 个人切片第一帧为正片；前提、词界与结尾仍可理解，重构图随真实机位边界改变。

## 3. 时间映射与取帧

- [ ] 每个时间字段标明源、正文或成片坐标；视频使用 `[start, end)` 半开帧区间。
- [ ] 镜头、声音、字幕与效果共用编辑映射，删段、重排、片头和插卡已传播到各层。
- [ ] 容器 PTS、分析音频归零、编码预延迟与 skip-samples 的处理明确；没有重复加片头或延迟补偿。
- [ ] 参考同步覆盖首、中、尾及所有分段接头；漂移校正有多点测量依据。
- [ ] 代表性取帧已对照目标源时间和实际解码 PTS，未把 seek 后第一张画面直接当作目标入点。
- [ ] 输入／输出帧率的正常量化容差与额外时间偏移分开记录；不存在通用的固定预读秒数假设。
- [ ] 段帧数、总帧数、母带样本数与预期呈现时长对应；没有长冻结填补缺录。

## 4. 对白与颜色

- [ ] 音轨内容、声道关系和主对白源经过试听；没有把双声道自动当成两个人。
- [ ] 对白逐句平衡，笑声不过度刺耳；片头与音效不遮字，最终全片测过响度和真峰。
- [ ] 局部修音保留处理区间与方法，前后复听；承诺不改的区间有适用的对比检查。
- [ ] 未重复处理已达标的源；去点击、降噪、压缩没有明显损伤语音。
- [ ] 色彩空间、传递曲线和范围有依据；10-bit、HDR、Log 与 Rec.709 未混淆。
- [ ] 分散同刻画面对比过肤色与共有中性物体；检查白衣纹理、暗部和局部色块。

## 5. 字幕结构与真实文字

- [ ] 原始 ASR 片段内部也检查过回合；换人、插话和未知短应答保留独立边界。
- [ ] 一条字幕只含一个回合；同一人物在插话前后未被错误合并。
- [ ] 前条停留未越过下一回合起点；真实重叠有明确回听记录与显示方案。
- [ ] ASR、声纹和模型分数被当作线索；专有名词、数字、否定与引言已按记录回听。
- [ ] 只改断句的修订验证过无空白文字序列、顺序和恰好一次使用；纠字有独立依据。
- [ ] 显示字幕与 SRT 来自同一源及映射，未分别改字；无意外重叠、重复和遗漏。
- [ ] `待核`、`待审核`、`unknown`、模型分数和制作备注未出现在交付字幕中。
- [ ] 未听清处有独立疑点记录；没有为了消除疑点删掉关键否定、数字或限定。

## 6. 包装与手机阅读

- [ ] 字幕用实际字体测宽，最多两行；长句、极短应答和快速换人做过真实视频预览。
- [ ] 上黑区主题、花字与下黑区字幕层级清楚，没有同时争抢阅读。
- [ ] 效果不挡脸、手势、字幕和必要信息，连续动作期间也满足。
- [ ] 花字按实际词时出现，多步回答逐项显现，没有提前剧透下一句。
- [ ] 每个效果可追溯到保留源区间；删掉源后已删除或重新审定对应效果。
- [ ] 完整节目片头的人物、期号、主题、声音和画幅均为本期；没有重复叠字。
- [ ] 最终画面按真实手机尺寸播放，并核查目标平台控件遮挡；未仅凭固定坐标宣称安全。
- [ ] 字体、音乐、音效和外来图形有记录的使用依据，可重建资产不依赖临时链接。

## 7. 最终文件与声音封装

- [ ] 最终 MP4 重新完整解码；实际帧数、时长、画幅、恒定帧率、色彩与预期相符。
- [ ] 只保留所需的视频和声音轨，没有意外继承时间码轨或无关元数据。
- [ ] 编码后的画面流与完整音轨分别检查，再验证最终封装，未仅以限视频帧数推定声音完整。
- [ ] 声轨复制路径核对包内容、数量、PTS/DTS、时长及 skip-samples；重编码路径核对母带与呈现首尾。
- [ ] 最终文件首、中、尾、剪口和插入段重新检查声画同步，尾音没有截断。
- [ ] 黑帧检测针对正文有效区域，不把竖版设计黑区判为正文故障。
- [ ] 疑似缩略图问题回看实际成片或无损原尺寸帧，结论不只来自缩小图集。

## 8. 结论、复现与交付

- [ ] 修复记录区分根因、触发条件、影响范围和症状；不确定的根因标为诊断或缓解。
- [ ] 修复前重现了失败条件，修复后证明负责边界的不变量成立；共享机制的相邻消费者已评估。
- [ ] 检测方法有适用范围；需要时用已知偏移的阳性对照验证能力，没有为过检随意改阈值。
- [ ] 输入身份、工具版本、字体、渲染参数和缓存失效关系可追溯，输出报告绑定当前文件。
- [ ] 完整人工视听实际完成与否、抽查位置、尚未确认事项都明确记述。
- [ ] 推荐交付与失败候选分开，历史版本保留，附工程入口、映射和同版本字幕附件。
- [ ] 本地导出、上传和发布分别有状态；没有把“技术检查通过”写成“全部内容无误”。

## 检查结果能证明什么

| 方法 | 可以支持的结论 | 单独不能证明 |
| --- | --- | --- |
| 清单与哈希 | 检查的文件身份、素材是否改变。 | 素材内容正确、独立备份存在。 |
| 映射与字幕契约检查 | 区间、引用、回合和字段符合所设契约。 | 源声音已听清、发言人已正确识别。 |
| 完整解码与参数检查 | 编码可解码、媒体参数及长度符合预期。 | 镜头自然、词义正确、口型连续。 |
| 波形与包级比较 | 在方法适用范围内的偏移、声音包或尾部完整性。 | 所有对白逐句平衡、没有主观听感问题。 |
| 抽帧和短样片 | 已列明位置的版式、字形、取帧或转场表现。 | 全片每帧无误、完整观看体验。 |
| 完整人工视听 | 该审核人实际看听过的版本与反馈。 | 尚未看的新导出同样通过、发布已经完成。 |

审片报告可以写“文件完整解码通过；首、中、尾与三个剪口检查通过；字幕尚未逐句听审”。这比一个没有检查范围的绿色“通过”更有用。
