# TBD 播客制作入口

用真实对白和人物反应构成可完整观看的播客：声音清楚、问答连贯、切镜有因，综艺效果服务理解。用户选择的内容范围、制作源和交付形式优先于这里的工作默认。

## 输入与产出

读取创作者提供的媒体、现有工程、最新意见及授权。优先沿用能追溯的现有记录；没有工程时建立一份制作记录，至少写明：

- 当前阶段、推荐版本和输出目标。
- 当前制作源的文件身份与 SHA-256，替代旧源的范围。
- 本轮已授权的工作，以及已有的审片确认所对应的具体文件。
- 编辑映射、字幕唯一源和工程入口。
- 已检查范围、未解决事项、下一步。

阶段结果是可播放文件及其可恢复工程和证据；单独列出技术通过、内容听审、创作者确认与发布状态。

## 选择流程

只读取当前任务需要的配套技能。它们与本技能安装在同一个父目录，各自可单独使用。

| 当前任务 | 配套技能 | 预期结果 |
|---|---|---|
| 接收素材、相机分段、漂移或声画对齐 | [tbd-ingest-sync](../tbd-ingest-sync/SKILL.md) | 素材清单、当前源身份、同步映射 |
| 内容取舍、多机位、停顿与对白处理 | [tbd-roughcut](../tbd-roughcut/SKILL.md) | 完整纯横版与统一编辑映射 |
| 转写校对、换人字幕、词时与 SRT | [tbd-captions](../tbd-captions/SKILL.md) | 字幕唯一源、字幕文件与独立疑点 |
| 竖屏布局、花字、音效或个人切片 | [tbd-packaging](../tbd-packaging/SKILL.md) | 包装配置、对应成片与效果来源 |
| 导出、音轨封装、技术检查与交付 | [tbd-delivery-qa](../tbd-delivery-qa/SKILL.md) | 最终文件、验证报告与准确状态 |

默认先导出完整 16:9 横版：有同步对白和基础调色，无字幕、黑边和包装。创作者确认视频部分后再做字幕与完整包装。技术样片、转写和抽帧都不能代替完整横版的确认。

用户已针对当前制作源明确授权继续字幕、包装或修改正文时，按这项有效授权推进，记录适用范围，不重复索要确认，也不补写旧版已获确认。只改字幕或包装、正文未变时复用已有依据；正文变化则更新映射和受影响输出，判断现有授权是否覆盖后续阶段。

缺少关键素材或必需决定时，完成仍有依据的准备工作并准确列出阻塞点，不编造缺失对白、同步依据或审片状态。能进行机器检查但尚未完整听看时，交付为相应阶段的候选版。

## 工作默认

这些是起点，可随平台、素材和用户要求调整，不能称为平台强制规格。

- 横版：1920×1080；完整包装：1080×1920，横幅正文等比居中。
- MP4 / H.264，25 fps 恒定帧率，SDR Rec.709 limited；先判断源色彩再实际转换。
- AAC，48 kHz，双声道，约 256 kbps；整片约 −16 LUFS，真峰不高于 −1.5 dBTP，并以试听复核。
- 字幕优先一行、最多两行，换人必须另起条目；内部疑点不出现在视频或 SRT。
- 个人切片第一帧直接进入正片，不自动继承完整版片头。

## 贯穿全程的约束

原始媒体、共享母版和历史交付只读，改动生成新版本。画面、声音、字幕和效果从同一编辑映射派生；源时间、正文时间和成片时间必须能相互追溯。

ASR、声纹分数和波形相关是线索，不能替代听到的证据。保留真实前提、否定、数字和回应，不移用别处反应制造事件，不把未经核实的原话包装成事实结论。

使用可用的本地工具或已有剪辑软件。FFmpeg、ASR、渲染引擎与插件是可替换能力，不假设专有 MCP、商业订阅或云服务必需；调用收费或外传媒体服务需在用户授权范围内。字体、音乐、音效和品牌资产使用创作者自有或许可明确的素材。

遇到故障，先分清来源、同步、编辑映射、取帧、字幕、渲染或封装的责任层。用可复现证据修正拥有不变量的共享机制，再重建受影响输出；不要给每段叠加固定偏移或局部例外。依赖未变的已验证成果可复用，但报告必须绑定当前文件。

交付说明给出版本、时长、改动、实际检查范围和待复核项。制作授权不自动包含上传、发帖或替他人发布。
