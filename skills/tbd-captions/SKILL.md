# 词时、回合与字幕唯一源

## 输入与产出

输入为当前制作源、编辑映射、可选 ASR 初稿与修改意见。产出为可编辑字幕唯一源、同版本 SRT、用于渲染的数据和独立疑点记录。未听清或未完成听审的状态留在制作记录中。

使用可用的本地或已授权转写工具，不绑定 ASR 模型、声纹库或云服务。渲染器可替换，但须读取同一份字幕数据。

## 建立唯一源

为每条字幕保存稳定 ID、媒体 ID 与哈希、时间基准、源起止、源片段 ID、文本和显示行、说话人、回合 ID、强制断开依据。另存疑点与校对证据。最终帧范围由这些数据和编辑映射派生；SRT 与显示字幕不得分别改字。

源时间、正文时间、成片时间要分清。ASR 若依据归零后的音频，其词时先映回选定源时钟；删段、重排或片头变化后重新映射，不能只整体平移全部字幕。区间统一为 `[start,end)`，明确毫秒到帧的舍入策略。

## 先分回合，再排版

1. 检查源片段内部是否已经混入问答、纠正、插话或接说。ASR 片段 ID 不定义说话回合。
2. 换人必须新建条目，默认从新发言开始切换；不同人的话即使很短也不能合成一条。显式插话、强制断点与归属不明短应答都禁止跨界合并。
3. 只有已确认同一回合的连续内容才可按语义合句。插话前后同一人也可能属于不同回合；身份相同不是合并的充分条件。
4. 核查真实词界。片段头尾可能含他人尾声，不可将整段声纹标签直接赋给每个词；有声音证据才拆分或收紧时间。
5. 再做一行优先、最多两行的排版，以实际字体测宽，不在词内硬拆。最短显示时长和停留延长必须服从下一回合起点，不能将前一人的话拖到后一人的声音上。

判断说话人使用声音、上下文与连续画面。双单声道不按左右轨分人；镜头、问句形式、单帧嘴形或未经校准的声纹分数不足以确认身份。证据不足时在内部记为未知，保持短应答独立；未知标签不显示在交付字幕中。

## 语义校对与疑点

ASR 是定位和初稿。优先复核专名、数字、年龄、英文、专业词、否定句及将被突出展示的原话。另一模型、旧转写、上下文合理或多次一致只能帮助发现分歧，不能作为自动投票真值。

保留人物自己的表达，可纠正错别字、合理断句和适度减少无意义重复，不擅自改为更书面或更“正确”的术语。不把说话人的观点、经历或未经核实的主张改写为事实结论。

疑点记录具体源与成片位置、候选词、听到的证据和仍需检查内容。试剪里对无法确认的非关键口头碎片可保守精简，但保留原音和缺词记录；不能靠删除否定、数字或限定来掩盖不确定。精剪需逐句听审并复核所有简写处。

视频、SRT 和观众可见字幕中不得出现“待核”“待审核”、unknown、模型分数或内部备注。尚有重要疑点时将交付明确标为候选版，不能以隐藏标记的方式冒充已校对完成。

## 检查与交付

- 仅改断句时，去掉空白与换行后的原文字序列应一致，每个保留源片段恰好使用一次；纠字另记理由。
- 检查一条只含一个回合、强制断点未吞掉、未知短应答未合并、无意外时间重叠、保留内容无重复遗漏。真实抢话仍保留独立回合，采用支持并行字幕的明确扩展契约；本仓库最小 JSON 契约只支持单层字幕，不能用它验证并行方案。
- 从最终映射重新生成 SRT 和渲染数据并比对文本与时码；抽看烧录成片的长字幕、快速换人和极短应答。
- 用实际字体和手机播放尺寸验证可读性，记录检查覆盖范围。

文本序列一致只证明与指定字幕版本一致，回合结构通过也不等于所有人物身份已被听审。交付报告分别陈述数据验证、实际听审和创作者确认状态。
