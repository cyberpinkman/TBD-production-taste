# TBD 的叙事与视觉品味

TBD 风格来自对真实交谈的耐心：保留人物想清楚一件事的过程，让另一个人的回应有位置。黑区、亮色花字和短提示音只负责强调已经发生的事。

本页区分**必须**保留的表达原则、**默认**设计起点和**待验证**的观感。时间、素材与审核要求见[制作规范](production-standard.md)，实际步骤见[制作流程](workflow.md)。

## 1. 一段好看的对话怎么留下来

先找清楚这一段的四件事：问题是什么，讲述怎样推进，哪里出现真实反应，怎样自然结束。主题切换可以慢一点，但观众应知道人物为什么说下一句。

| 情况 | 默认选择 | 判断依据 |
| --- | --- | --- |
| 一个人稳定讲述 | 用合适的近景，允许停留。 | 观众需要看表情与措辞，不需要每几秒一次切镜。 |
| 短问答、双方笑起来 | 留全景或切到同时刻的真实反应。 | 保住问答关系、反应先后和空间关系。 |
| 思考、轻声或犹豫 | 先回听，判断它是否有表达作用。 | 沉默可能承载情绪；ASR 空白不是删除指令。 |
| 设备讨论或重复铺垫 | 确认没有必要信息后收紧。 | 剪掉制作噪声，不误删恢复访谈后的正常插话。 |
| 某机位不清楚或缺录 | 用有效的同步机位。 | 不为“谁说话就一定看谁”牺牲可看性。 |
| 画外有人回应 | 按内容功能保留声音，必要时留全景。 | 人不在画面中不代表回应无用。 |

**必须：** 笑点保留建立、停顿和回应的关系。可以缩短无作用的等待，不能剪成虚假因果。画面中的人、字幕问号、单帧嘴形都不是判断发言者的充分依据。

下面只是一段虚构对话，说明回合与包装的关系：

> host：「你最后用了哪个办法？」
>
> guest：「先把通知关了。」
>
> host：「就这么简单？」
>
> guest：「第一天是。」

四个回合各自成条。先听到“第一天是”，再让对应强调出现；不要在第二句时提前亮出结尾，也不要从别处找一张笑脸接上去。

## 2. 黑区不是填空，是阅读层级

**默认：** 完整竖版保留横幅正文，不把双人访谈强裁成满屏大脸。上方承载节目或本段主题和偶发花字，下方承载主字幕，人物画面留给表情和动作。

以下是 1080×1920 的参考布局；坐标为画布像素，供启动设计使用，**不是平台安全区证明**。

| 层 | 参考位置 | 使用原则 |
| --- | --- | --- |
| 底色 | 全画布 | 近黑，提供稳定对比。 |
| 节目／本段主题 | 上黑区，主题可从 `x=75, y=357, w=930, h=230` 起试 | 信息少且层级清楚；不要常驻堆满多行介绍。 |
| 正文画面 | `x=0, y=656, w=1080, h=608` | 16:9 横幅的偶数像素近似；等比缩放，用极小补边处理取整，不非等比拉伸。 |
| 主字幕 | 下黑区，视觉中心约 `y=1340`，宽不超过 `920` | 避开平台控件；实际字体测宽，并在手机上检查。 |
| 花字 | 优先上黑区；有空间才进入正文 | 花字出现时可暂隐常驻主题，避免两个标题争抢阅读。 |

**必须：** 人脸、关键手势、主字幕和必要信息不被效果遮住。近景空间不足就用黑区。全景的桌面空区可以承载短效果，但先检查整段动作，不只检查一帧。

标题、人物标识与正文字幕各有角色：标题说明“正在聊什么”，字幕承接“正在说什么”，花字强调“这一刻为什么值得注意”。不要让三层重复同一整句话。

## 3. 黄、粉、青的使用方法

以下是现有视觉语言提炼出的**默认**配色，可用于社区项目的自有图形。颜色不是情绪识别结果，也没有强制的人物绑定。

| 色彩 | Hex | 建议用途 |
| --- | --- | --- |
| 黄 | `#FFE431` | 主强调、关键词、集中线。 |
| 粉 | `#FF3F8F` | 第二重强调、短反应、对比元素。 |
| 青 | `#34DDF2` | 问句、补充关系、次级强调。 |
| 近黑 | `#0C0C10` | 底色、轮廓或字边。 |
| 白 | `#FFFFFF` | 主字幕与主要阅读信息。 |
| 灰 | `#A5A5AC` | 次要标注；避免用于小字号重要信息。 |

一处效果通常只需要一个主色与一个辅助色。以高对比、粗字重、简洁框形和明确进入／退出形成节奏；不让每个词都抢主角。字号和颜色在真实画面上检查，不能只在设计稿中评估。

## 4. 字幕的第一职责是让人听懂

**默认：** 无衬线中文字体，白字，下黑区居中。1080 像素宽画布可从约 50 px 试起；优先一行，必要时两行，宽度不超过约 920 px。使用可合法分发或由使用者自行安装的字体，记录字体版本；实际渲染测宽，不按字符数猜宽度。

**必须：** 先分说话回合，再做行长和时长调整。禁止为了凑长字幕将不同人的短句拼在一起。读不完时，优先检查分句与无意义重复；不能将前一人的字幕拖到下一人发言后，也不能删掉关键条件。

主字幕维持稳定位置和基本样式。少量词语需要强调时交给独立花字；不要给每条正文字幕都加夸张动画。出现真实抢话时先回听，再决定是否使用明确的并行字幕版式。

## 5. 综艺效果必须跟着真实事件走

可用的语言包括弹入问句、漫画框、分阶段文字、短集中线和轻提示音。它们没有固定分钟配额；一段自然流畅的对话可以完全没有花字。

每个候选先写清：原话或编辑评论、对应源位置、需要的上下文、出现与消失条件、挡住什么、是否需要声音。满足这些条件再上时间线：

1. 原话已回听确认；编辑吐槽明确写成“编辑小字”等身份，不制造署名。
2. 关键词说出后才出现对应强调。列举和多步回答按实际进度逐项显现。
3. 确实帮助理解、标记反转或放大已有反应；去掉它时内容仍然成立。
4. 不遮人物、动作和字幕；画面在移动时也成立。
5. 严肃、脆弱或痛苦的表达按当下情绪处理，不机械套喜剧效果。
6. 音效不盖对白、不冒充现场笑声，外来资产具备可使用的依据。

如果源区间被删，绑定的效果一起失效。重新选择效果必须重新看上下文，不能将其他时刻反应挪来补齐。

## 6. 完整节目与个人切片

完整节目的片头是**可选默认项**，长度和形式仍待比较。需要片头时逐集检查节目名、期号、人物和主题；复用自有品牌元素，不盲用旧成片。片头已经带文字就不重复叠字。

**必须：个人切片不加片头。** 第一帧直接进入正片，开场吸引力来自有意义的原话。可以在正片上常驻短标题，但不另占时间做标题卡，也不把必要前提、词头或结尾剪掉。20–60 秒可作选题起点，不是强制时长。

近景重构图随实际机位边界改变，检查边界前后帧，避免单帧尺寸跳变。切片要能独立理解，但不能为了独立成篇而虚构一个新意思。

## 7. 怎么判断“像 TBD”

关掉包装后，对话仍然清楚自然；打开包装后，重点更容易跟上，人物仍是观看中心。这是风格的检查方向，不能用效果数量自动评分。

**待验证：** 长时间观看是否疲劳，短应答在手机上是否可读，上黑区品牌是否过大，提示音是否打断情绪，以及平台控件是否遮挡。先用快速换人、长字幕、全景动作、近景和严肃段落做代表性预览，再完整观看。记录实际看到的范围，使用[质量检查单](quality-checklist.md)区分技术结果与审片结论。
