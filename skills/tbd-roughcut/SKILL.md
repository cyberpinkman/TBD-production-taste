# 叙事粗剪与对白

## 输入与产出

输入为当前授权制作源、同步映射、内容范围与修改意见；转写仅作定位线索。产出为完整可播放的 16:9 横版、编辑映射、内容删改及声音处理记录，默认无字幕、上下黑边或其他包装。

使用现有 NLE 或 FFmpeg 等具备相应能力的工具。专有音频插件不是前提；先诊断，再选择处理方式。

## 内容与镜头

1. 明确本集主题、保留范围和已授权删改。以完整问答和叙事单元选段，保留必要前提、否定、数字限定及结尾，不能为强开场剪掉词头或改变因果。
2. 准备口令、思考停顿、重复和离题按语境判断。ASR 空白不等于静音：结合原音、波形、局部能量或语音活动检测，保护轻声、呼吸、笑声及词头词尾。有冲突的候选先保留。
3. 镜头服务发言、真实反应与叙事。主体叙述可用近景，短问答和共同反应用全景；不按固定秒数轮换，不移用别处反应制造情节。
4. 切镜画面不是人物身份的唯一证据。听原声并参考连续画面，不凭单帧张嘴、字幕问号或左右声道猜发言者。
5. 删段、重排和切镜统一写入编辑映射；源区间与输出帧用半开区间 `[start,end)`。画面、声音和后续字幕使用同一映射，检查每个剪口的语音、动作与环境底噪。淡变不能吞掉发言或改变同步。

某机位缺失时优先以有效机位覆盖已选内容。低质量画面不过度放大、锐化或重复转码。用户指定处理后母版时沿用其指定的画面与对白，不自动换回旧相机或独立录音。

## 声音处理

先抽听提问、叙述、抢话、笑声与安静段，判断每条轨实际记录了什么。双声道可能是混合拾音或双单声道，不能直接丢轨或按左右轨分人物。

需要处理有损源时先解码为保留余量的浮点母带，完成增益和混音再量化。检查相位、音色、噪声和峰值。现有母版达标且无听感问题时，不重复叠加降噪、压缩或响度处理。

咂嘴和短脉冲先定位并区分语音，优先仅对证据明确的非语音瞬态施加平滑增益包络或经对照验证的修复方法。全片去点击可能损伤辅音；不得把某次衰减量、淡变长度或插件预设当成普遍解法。

记录处理区间、方法和参数，并复听前后。承诺局部修音时，检查区间之外保持一致；格式、重采样、量化可比较时可做样本差值验证。剪口另外检查突变、底噪与听感。

对白平衡靠逐句复听，不仅看全片平均值。可从整片约 −16 LUFS、真峰不高于 −1.5 dBTP 的工作目标开始，但数字通过不代表听感自然。包装加入音效后必须重新测最终整片。

## 基础调色

先查颜色空间、传递曲线、范围与高光，再决定转换。10-bit 不代表 Log 或 HDR，写标签也不是实际色彩转换。

选至少三个分散的同刻场景比较同一人的肤色及共有中性物体，先亮度、白平衡、肤色，再风格。先输出短切换对照，检查肤色、白衣纹理、暗部和局部色块，再重导。用户指定美颜或调色版时保留该外观，不未经要求重做。

## 横版交付

默认输出完整 1920×1080 横版，有同步对白、基础混音与调色。先检查风险剪口和首中尾，再输出全片并完整解码；记录版本、哈希、帧率、帧数、时长和映射身份。

附改动与待办，准确区分技术检查、实际听看和创作者确认。默认横版经创作者确认后进入包装；本轮已有明确继续制作授权时按其范围推进，不重复请求，不追认旧版审片状态。正文返修重建受影响映射及派生输出，保留历史版本。
