# 素材接收与同步

## 输入与产出

输入是创作者提供的相机文件、录音、处理后视频和素材说明。产出为素材清单、缺失与解码诊断、选定制作源、同步映射和检查记录；素材整理不等于内容定稿。

可使用 `ffprobe` 获取流信息、`ffmpeg` 解码和提取分析音频，或使用具备同等能力的剪辑软件。任何 ASR 或波形分析器都可替换；不依赖指定云服务。

## 接收与锁源

1. 实际列举所有素材与相邻分段，包括重启录制文件。核对文件内容，不能只按文件名、设备时间或创作者口述判断身份。
2. 每个文件记录稳定 ID、原文件名、机位或角色、来源与项目路径、大小、SHA-256、时长、分辨率、帧率及是否可变、色彩标签、音轨和采样率。区分原件、项目副本、代理和交付。
3. 首次使用时完整解码各必要流，抽看每段首、中、尾，记录可用区间与缺失。代理便于剪辑，但不等于原片备份。
4. 原件只读；转码、调色、修音生成新文件。收到已处理版本时，记录它替代哪些画面与声音、允许何种后续修改，并锁定哈希。旧转写可作为参考，旧媒体不得悄悄回流。
5. 每段自动分割或重启文件独立建档。相邻文件时长相加不证明连续；某机位缺失不自动缩短整期到全部机位的共同交集。

## 同步与共同坐标

选择覆盖充分、连续可靠的媒体作为参考时钟，不因此让该机位或声音全程优先。使用媒体 PTS 和共同声音定位，设备时间仅辅助。

用共同拍手、清晰语音或其他声音定位候选偏移，再以共同动作复核。覆盖首、中、尾及每处分段或重启接头。重复波形、低能量和不同拾音频响会造成误匹配，记录候选匹配的证据；只有测到持续漂移才拟合速度或分段校正。

映射至少包含以下信息：

| 层级 | 字段与含义 |
|---|---|
| 素材时间 | 文件 ID、源时钟原点、源入出点、参考坐标、偏移和有证据的速度校正 |
| 正文时间 | 每个保留区间映射到的输出帧起止，不含片头 |
| 成片时间 | 片头或插卡加入后的最终帧范围 |

视频以输出帧号和半开区间 `[start,end)` 表示；音频保留采样级或足够精度的秒数。显式记录变换方向与单位，镜头、音频、字幕和效果共享映射。分析音频若归零，词时必须映回选定的源时钟；记录容器起始 PTS、skip-samples 和解码策略，避免重复补偿。

换制作源后重新核对时长、帧率、声画关系及旧时码适用性。相似画面不证明相同时间线；不复用上一期测得的偏移、漂移率或误差阈值。

## 取帧正确性与同步验收

长 GOP 或 HEVC 素材需验证真实取到的帧。抽查代表性入点和保留段首、中、尾的解码 PTS；若 seek 丢失预期入点，先提前解码，再按源时钟 trim 和换帧率。不能把第一张碰巧取到的帧重标为零后声称同步正确。

相机同步、取帧偏移、处理延迟和最终封装延迟分别诊断。容差按源与输出帧率及任务需要制定，将正常帧量化与额外偏移区分。修复共享取帧机制后检查所有受影响消费者，不为各片段分别硬加补偿。

交付同步报告时写明实际检查的文件与时点、各段偏移、接头覆盖策略、未验证范围。相关峰或抽帧证明仅限其检查范围；未完整试听不能写成全片声画已确认。
