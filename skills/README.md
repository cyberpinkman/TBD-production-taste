# TBD production skills

这六个技能把 TBD 风格制作中的判断方法整理为可安装指令，供创作者使用自己的素材。它们不包含节目原片、真实对白、品牌资源或第三方插件代码，也不会仅凭安装自动完成媒体渲染。实际制作仍需要媒体工具及相应素材。

## 安装

在仓库根目录运行：

```sh
python3 scripts/install_skills.py
```

安装器优先使用 `$CODEX_HOME/skills`，未设置时使用 `~/.codex/skills`；也可用 `--dest` 指定目录。任何同名技能已存在时，在复制前停止，不覆盖已有修改。也可手动将六个 `tbd-*` 文件夹整体复制到工具支持的 skills 目录。每个子技能都包含执行所需规则，入口技能通过同级目录路由；安装后不需要依赖仓库 `docs/` 的相对路径。

这些是原创新写的开放技能，不安装或复制本机已有第三方技能。FFmpeg、转写器和渲染引擎按各自安装方式与许可准备；专有 MCP、商业订阅和云服务不是必需依赖。

## 选择技能

| 技能 | 使用时机 | 主要产出 |
|---|---|---|
| [tbd-production](tbd-production/SKILL.md) | 整期制作、续作或跨阶段返修 | 阶段计划、制作记录、正确的下一步 |
| [tbd-ingest-sync](tbd-ingest-sync/SKILL.md) | 收素材、分段机位、处理后源或同步诊断 | 素材清单、源身份、同步映射 |
| [tbd-roughcut](tbd-roughcut/SKILL.md) | 内容取舍、镜头、停顿和对白 | 完整纯横版、编辑与声音处理记录 |
| [tbd-captions](tbd-captions/SKILL.md) | 转写、换人字幕、词时或断句校对 | 字幕唯一源、同版本 SRT、独立疑点 |
| [tbd-packaging](tbd-packaging/SKILL.md) | 竖屏、花字、提示音或个人切片 | 包装工程、效果时间线、成片 |
| [tbd-delivery-qa](tbd-delivery-qa/SKILL.md) | 导出、音轨封装和交付复核 | 验证报告、准确状态、交付清单 |

## 调用示例

在支持技能调用的 Codex 中，可附上自己项目的实际素材和工程路径后输入：

```text
$tbd-production 用我提供的双机位和录音制作一集 TBD 风格播客。
先做完整纯横版。保留完整问答，我会在审片后给出内容意见。
```

```text
$tbd-ingest-sync 检查这些分段文件和独立录音。
输出素材清单、首中尾及重启接头的同步证据，不要假设相邻文件连续。
```

```text
$tbd-captions 使用当前正文和编辑映射校对字幕。
换人必须另起条目，SRT 和烧录字幕使用同一源，未听清的内容单独记录。
```

```text
$tbd-packaging 依据我已指定并授权继续制作的正文做一条个人切片。
第一帧直接进正片，不加片头；使用我自己的标题和品牌素材。
```

```text
$tbd-delivery-qa 检查本版最终 MP4、SRT 和封装前母带。
重点核对字幕回合、首中尾同步、音轨尾部和实际检查覆盖范围。
```

技术检查、完整听看、创作者确认和正式发布分别记录。机器转写和抽帧不能代替听审；缺素材时技能会列出缺口，已有明确授权不会被重新请求。
